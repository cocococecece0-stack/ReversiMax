# ReversiMax

Реверси (Отелло) против ИИ — нативное Android-приложение на Kotlin + Jetpack Compose.

## Что умеет

- **Полные правила Реверси**: легальные ходы подсвечиваются на доске, перевороты фишек — с анимацией.
- **ИИ на негамаксе с альфа-бета отсечениями**: статические веса клеток (углы = +20), бонус за подвижность, полный перебор в эндшпиле.
- **Три уровня сложности**: Лёгкий (жадность + шум), Средний (глубина 4), Сложный (глубина 7).
- **Подсказка** — подсвечивает лучший ход по версии движка «Сложный».
- **Отмена хода**, подсчёт очков в реальном времени, выбор стороны (чёрные/белые).
- Тёмная «космическая» тема, фишки с мягкими градиентами.

## Сборка

```bash
./gradlew test          # JVM-тесты игровой логики и ИИ
./gradlew assembleDebug # отладочный APK
./gradlew assembleRelease
```

CI (`.github/workflows/android.yml`) прогоняет тесты, собирает подписанный release-APK
и публикует его в GitHub Releases как asset релиза `ReversiMax.apk`.

## Структура

```
app/src/main/java/com/reversimax/app/
├── GameEngine.kt        # чистые правила Реверси (без Android) — покрыты тестами
├── ReversiAi.kt         # альфа-бета движок
├── MainActivity.kt      # Compose UI + состояние партии
└── ui/Theme.kt          # тёмная тема
```

## Тесты

`app/src/test/` — проверяют стартовую позицию, легальность ходов,
корректность переворотов, терминальные позиции, полный автоплей
и победу ИИ уровня «Средний» над жадным игроком.
